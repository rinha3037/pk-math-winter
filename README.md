# PK수학 방학 특강 선착순 신청

학부모가 로그인 없이 바로 신청하는 선착순 접수 페이지와, 신청·결제 현황을 보는 관리자 페이지입니다.
여름·겨울 특강마다 관리자 페이지의 '시즌 설정'만 바꿔서 계속 씁니다.

- 신청 페이지: https://rinha3037.github.io/pk-math-winter/
- 관리자 페이지: https://rinha3037.github.io/pk-math-winter/admin.html
- 설정 방법: [SETUP.md](SETUP.md)

| 파일 | 내용 |
|---|---|
| `index.html` | 학부모 신청 페이지 |
| `admin.html` | 관리자 페이지 |
| `config.js` | 구글 Apps Script 주소 (한 줄) |
| `api.js`, `common.css` | 두 페이지 공용 |
| `apps-script/Code.gs` | 구글 시트에 붙여넣는 서버 코드 |
